02 / SALESFORCE

NGO Donor & Programme Management

A Salesforce application for donor and programme management, built around custom objects, automation and a dashboard experience.

DONORSPROGRAMMESOPERATIONS

Problem

Donor and programme work needs a connected view of people, activities and operational processes.

Solution

A Salesforce platform using custom objects, Apex, SOQL, Lightning Web Components and Flows.

Architecture

Custom objects model the application domain; Apex and Flows support automation; Lightning Web Components provide the user-facing application and dashboard experience.

Key decisions

Platform-native model

Custom objects and workflows keep donor and programme work connected within Salesforce.

Quality evidence

Test classes and Apex coverage give the implementation a measurable quality signal.
