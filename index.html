03 / FLAGSHIP PROJECT

The build I keep coming back to

A full-stack heritage cataloguing platform, taken from a broken codebase to a tested, deployable application.

Heritage Site Information System

A Django platform for cataloguing, exploring, and visualising heritage sites — rebuilt end to end with a real database layer, automated testing, and a CI/CD pipeline.

▶ Live demo Source ↗
DjangoPostgreSQLMongoDBDockerGitHub ActionspytestBootstrap 5Chart.jsRender.com/

This started as a broken, half-working codebase and became the centrepiece of my portfolio. It runs a dual-database architecture — PostgreSQL for structured, relational site records and MongoDB for flexible, document-style heritage data — sitting behind a Django backend. The frontend uses Bootstrap 5 with Chart.js for visualising site data (categories, regions, condition reporting), and the whole thing ships through a GitHub Actions CI/CD pipeline running 45 automated tests before anything reaches production.
