03 / DATA

NIDS Socio-Economic Wellbeing Analysis

A multi-wave analysis pipeline that prepares National Income Dynamics Study data for exploration of inequality, household wellbeing and recovery over time.

MULTI-WAVE
DATA → INSIGHT

Problem

Survey data collected over multiple waves requires careful cleaning and harmonisation before it can support comparisons over time.

Solution

A Python data pipeline built with Pandas and NumPy, followed by visual exploration with Matplotlib and Seaborn.

Architecture

Raw survey waves flow through cleaning and harmonisation into analysis-ready data, then into visual analysis of socio-economic indicators.

Key decisions

Cross-wave consistency

Cleaning and harmonisation make the analysis more comparable across survey waves.

Visual analysis

Charts help examine patterns in household wellbeing, inequality and recovery.
